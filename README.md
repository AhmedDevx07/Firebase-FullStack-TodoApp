# Firebase Full-Stack Todo App

A **modern, real-time Todo App** built with **Firebase** and **Vanilla JS / Bootstrap 5**, designed to help users manage their daily tasks efficiently.

---

## 🚀 Features

* **User Authentication**: Sign Up / Login with Firebase Auth
* **Real-Time Todos**: Add, Edit, Delete tasks with instant updates using `onSnapshot`
* **Personalized Tasks**: Each user sees only their own tasks
* **Task Categories**: Work, Personal, Urgent – color-coded for clarity
* **CRUD Operations**: Full Create, Read, Update, Delete functionality
* **Responsive & Modern UI**: Built with Bootstrap 5 and custom CSS
* **Firestore Security Rules**: Each user can only access their own data

---

## 📂 Tech Stack

* **Frontend:** HTML, CSS, JavaScript, Bootstrap 5
* **Backend / Database:** Firebase Firestore, Firebase Auth
* **Hosting:** Netlify (Live Demo)

---

## 🎯 Installation & Usage

1. **Clone the repository**

   ```bash
   git clone https://github.com/Ahmed-Devx/Firebase-FullStack-TodoApp.git
   cd Firebase-FullStack-TodoApp
   ```

2. **Open `index.html` in your browser**
   (or use a local server like VSCode Live Server)

3. **Sign Up / Login**
   Start adding your tasks and see them update in real-time!
